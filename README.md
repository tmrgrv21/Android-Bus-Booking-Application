# Tomar Bus Services – Android Bus Booking Application

Tomar Bus Services is a modern Android-based bus ticket booking application developed using Java, XML, and SQLite. The app provides a complete bus reservation experience, including bus search, seat selection, ticket booking, payment simulation, booking history, and animated bus tracking.

## Features

* User Registration & Login
* Search Buses by Source and Destination
* Auto-Suggestion for Cities
* Bus Listing with Fare and Timings
* Interactive Seat Selection (40 Seats)
* Dummy Payment Gateway Simulation
* Unique Booking ID Generation
* Booking Confirmation Screen
* Booking History Management
* Animated Bus Tracking Interface
* Light and Dark Theme Support
* SQLite Database Integration
* Modern Material Design UI

## Technologies Used

* Java
* Android Studio
* XML Layouts
* SQLite Database
* RecyclerView
* CardView
* Material Components
* SharedPreferences
* ObjectAnimator

## Project Structure

* Activities
* Adapters
* Models
* Database Helper
* XML Layouts
* Drawables and Resources

This project demonstrates Android application development concepts including UI/UX design, local database management, theme customization, data persistence, and real-world booking system implementation.
